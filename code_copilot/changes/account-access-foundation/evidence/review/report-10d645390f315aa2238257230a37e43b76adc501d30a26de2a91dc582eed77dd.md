## Findings 与处置

- **IMP-A（important）**：`test-spec.md` 的 P0-09 验收场景仍写「localStorage 只允许短租约元数据」——租约移除后该断言恒真，与修订后的 §4.3/AC-10 矛盾，属本 change 自己承认过的「假证据」类别。**已按复核建议改为**「持久存储不得含令牌或任何跨标签协调元数据（断言 localStorage 与 sessionStorage 均为空）」，改后断言可证伪。复核方复读确认关闭。
- **SUG-A（suggestion）**：`README.md:170` 句尾「该降级路径」指代歧义。**已改为**「该跨标签协调能力」。
- **SUG-B（suggestion）**：`knowledge/index.md:28` 称「未设置变量时整包 skip」，实际该包在未配置时仍有 1 个真实执行并通过的用例（守卫解析用例）。**已改为**「数据库用例逐条 skip（守卫解析用例 `harness_guard_test.go` 仍会执行）」。复核方复读确认关闭。
- **SUG-C（suggestion，deferred）**：`spec.md:96`「各标签各自刷新」是绝对表述，而 `createBrowserChannel()` 与 `createBrowserLock()` 独立装配——无锁但有 BroadcastChannel 时标签仍会消费广播令牌，因此「各自刷新」只在**并发刷新**这一意义上成立。不违反 AC-10，残余并发风险与 R2-F1 相同、未被本次改动改变。建议措辞限定或补一例「无锁 + 共享 channel」的用例。
- **SUG-D（suggestion，deferred）**：`REFRESH_LOCK_NAME`、`CSRF_COOKIE_NAMES`、`createBrowserLock`、`createBrowserChannel`、`SessionManager.clear` 在 `web/src` 内无外部消费者；**明确不是租约残骸**，属导出面冗余。
