# v3 审查协议（项目差异）

本文件是普通 Review 的唯一必读项目协议。通用审查规则（输入、独立性、只读边界、检查顺序、Findings、verdict 与 basis）以 Runner 的 review reference 为唯一权威，不在此重复；本文件只记录项目级差异与红线。

## 项目差异与红线

- 检查顺序、严重度映射、专项 reviewer 触发条件等按团队偏好在此补充；未补充时按 Runner 通用规则执行。
- 用户要求专项审查时按需读取 `spec-reviewer.md` 与 `code-quality-reviewer.md`，不能放宽本协议。
- 本项目必读的项目规则（与风险直接相关）：`rules/project-context.md` 及已生成的可选 rules。
