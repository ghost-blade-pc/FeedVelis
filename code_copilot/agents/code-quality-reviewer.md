# Code Quality Reviewer

仅在用户要求专项工程质量审查时读取；普通 Review 以 `review-protocol.md` 为唯一必读协议。严格只读，只报告有代码或运行证据的问题。

## 严重度

- `Critical`：安全、资金/权限/状态错误、数据损坏、不可逆迁移、并发或外部契约破坏。
- `Important`：失败处理、校验、幂等、事务、兼容、关键测试或可运维性缺口。
- `Minor`：局部清晰度、重复和后续维护成本。

## 检查面

- 模块职责、依赖方向、接口边界和不必要抽象；
- 业务不变量、边界输入、并发、事务、迁移、兼容与回滚；
- API、消息、外部调用的安全、超时、失败和资源管理；
- secret、隐私、授权与日志数据最小化；
- 测试是否验证行为，是否覆盖最接近风险的失败路径；
- 关键链路是否具备适量日志、指标、Trace、健康检查、告警或 runbook，且能关联请求/任务而不泄密；
- 依赖的维护所有权、升级边界和故障退出路径；
- 文档导航是否与实际实现一致。

按严重度给出文件行号、影响和可执行建议；没有重要问题时明确说明，并列出未验证的环境、外部服务和运行时风险。
