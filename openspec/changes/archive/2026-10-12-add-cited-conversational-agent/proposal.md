# 智能阅读助手：有引用的对话编排与 SSE

## Why

I5 第 1–2 步已交付账户私有会话、不可变消息和三个内部只读文章工具，但用户仍不能通过连续对话检索、获得推荐并追问文章。本变更补齐第 3–4 步，以可取消、可恢复查询的受控 ReAct 回合交付有真实来源的阅读回答，同时为后续笔记、外部搜索、写作和长期偏好记忆保留明确边界。

## What Changes

- 使用 Eino ADK 单 Agent ReAct 编排，服务端控制工具白名单、身份、检索约束、模型/工具调用次数、输入输出及总时间预算；生成模型使用独立配置。
- 新增独立执行回合：关联既有用户消息，持久化接受、执行及终态，支持 24 小时接受幂等、显式失败重试、并发限制、助手消息额度预留和进程中断收敛。原消息追加接口仍只保存用户消息。
- 新增结构化证据、回答片段、引用和文章卡片。完整片段经校验及当前公开修订复核后才能输出；历史和重放通过读取投影隐藏失效证据，不改写持久化消息。
- 新增回合创建、列表、详情、取消与 SSE 订阅接口。已确认：意外断线不取消回合，重连读取同一回合；只有显式停止、权限失效、超时、执行者丢失或关闭服务等条件终止执行。SSE 事件有序、有界持久化并支持续读。
- 读取有限成功历史与当前文章上下文；工具定义、上下文组装、证据来源和应用事件保持可扩展。首版只启用站内三个只读工具，不实现笔记写入、外部访问、写作产物或长期偏好存储。
- **BREAKING**：开启对话生成后，活动回合期间的新消息追加返回明确冲突；消息额度计算包含助手预留。助手历史增加回合关联与脱敏投影标记，历史正文可能因引用不可见而显示安全替代内容。已有创建、改名、用户消息规范化、幂等成功重放和删除标记语义继续保留。
- 增加真实依赖与确定性模型桩验收、通过 nginx 的 SSE 验证，以及运行预算和隐私观测。Web 对话页面与完整浏览器评测由 `add-agent-web-experience-and-evaluation` 承接。

## Capabilities

### New Capabilities

- `agent-runs`：本人回合的接受、执行、幂等、额度、取消、恢复查询、终态与删除联动。
- `agent-orchestration`：有界 ReAct、可信工具调用、有限上下文、独立模型配置及智能阅读助手的扩展边界。
- `agent-evidence`：本轮证据、片段级引用、来源卡片、无结果表达及历史可见性投影。
- `agent-streaming`：认证 SSE、持久化事件次序、断线续读、心跳、背压及代理链路行为。

### Modified Capabilities

- `agent-conversations`：受控助手写入、活动回合下的追加约束、助手额度预留、历史投影字段和会话删除时的回合/证据清除。

## Impact

- 后端新增领域回合/证据模型和应用端口；Eino、PostgreSQL、Hertz/SSE 与指标实现留在外层。复用 `agentconversation`、`agenttools`、认证当前事实、文章读取/搜索/推荐服务，不修改三个工具的只读契约。
- 增加递增迁移（当前最新为 `000012`，实施时确认下一编号），不改写已执行迁移；扩展 `backend/api/openapi/velis.yaml`、示例配置、`.env.example`、Compose API 透传和 `web/nginx.conf`。
- 生成执行由 API 内有界执行器和 PostgreSQL 协调，不新增 RabbitMQ、Redis、OpenSearch 或模型为会话核心 readiness 依赖。
- 实施时更新 README 的实际能力、Roadmap 的智能阅读助手方向及后续扩展顺序，补充配置/操作与集成测试文档；提案阶段不修改这些当前事实文档，也不部署或调用收费模型。
