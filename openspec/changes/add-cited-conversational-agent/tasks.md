# Tasks

本清单实施 I5 第 3–4 步；每组同时交付本组测试和文档。默认使用确定性本地模型桩，真实收费 Provider 仅显式运行。Web 页面和完整浏览器评测由下一 change 承接。

## 1. 领域规则与应用端口

- [ ] 1.1 定义回合六态、终态不可变、deadline、执行权和失败重试规则；单测覆盖全部允许/禁止迁移、同消息最多三次与一个成功回合。
- [ ] 1.2 定义助手额度预留、账户/会话活动上限和调用预算；单测覆盖最后名额、批量工具超额、失败尝试计数和未知 usage 的保守预留。
- [ ] 1.3 定义版本化证据、回答类型、片段、引用与安全错误分类；单测覆盖未知来源、跨回合引用、重复来源编号及失败 partial 不构成成功回答。
- [ ] 1.4 增加事务仓储、当前授权、证据事实、上下文、编排执行、事件读取及观测端口；使用替身完成契约测试，并通过现有 architecture 测试确认 Domain/Application 不引入 SDK、SQL 或 HTTP 类型。
- [ ] 1.5 在 Agent 开发文档记录状态图、锁顺序、端口职责和未来扩展边界；逐项对应五份 delta spec，明确当前不支持笔记、外部搜索、写作和长期偏好。

## 2. PostgreSQL 回合事实、接受与配额

- [ ] 2.1 确认下一迁移编号并新增回合、证据、片段和事件表及关联/唯一约束；专用 `_test` PostgreSQL 验证 up、空事实 down/up、有事实拒绝 down 和旧迁移未改写。
- [ ] 2.2 实现本人回合创建的严格命令、所有权及最新 user 消息检查；应用与数据库测试覆盖跨账户、助手/旧消息、上下文和约束规范化、非法 retry_of 与三次上限。
- [ ] 2.3 将原接受快照、24 小时幂等、回合及助手预留原子提交，扩展关联操作清理集合；真实数据库故障注入覆盖同键重放、异命令冲突、提交响应丢失和回滚后再接受。
- [ ] 2.4 在账户锁下实现每账户两个、每会话一个活动回合及助手额度；真实并发测试覆盖跨实例竞争、最后消息名额和不同副本一致配额，断言超限前没有模型调用。
- [ ] 2.5 调整原消息追加与排序：成功幂等重放先于活动冲突检查，预留不产生消息或序号；原会话回归与新测试覆盖并发追加、活动期间冲突、message_count 和降低配额后的最终拒绝。
- [ ] 2.6 实现回合列表/详情、独立用途的认证加密游标及安全摘要；测试默认/边界分页、同时间排序、跨账户/会话/用途、过期游标和读取不启动生成。
- [ ] 2.7 扩展会话删除与有界保留期清理；真实数据库测试覆盖删除与接受/写入竞争、全部私密载荷清除、原三字段删除标记、失败工作内容和全部事件 24 小时清理、成功引用保留及清理失败回滚。
- [ ] 2.8 补充数据与配额操作文档，说明最后一个名额可保存 user 但无法再生成、保留期和兼容回退；以迁移测试与删除查询结果验证示例，不通过删用户数据完成 down。

## 3. 证据、回答协议与历史投影

- [ ] 3.1 实现从实际保留工具内容建立本轮 article 证据，区分摘要/正文、修订及截断；测试裁剪内容不可引用、跨回合 ID 拒绝和同文章修订重复来源去重。
- [ ] 3.2 实现有界 NDJSON header/block/finish 解码器及版本化回答组装；拆包/合包测试覆盖 UTF-8、重复/未知字段、乱序、尾随垃圾、缺 finish、单行 64 KiB/累计 256 KiB 和数量/字符边界。
- [ ] 3.3 实现逐片段引用、正文取证要求与显式逐字引文校验；测试伪造/空引用、摘要无法支持正文细节、引文不匹配和非法尾部使已发片段保持 partial。
- [ ] 3.4 通过当前文章事实批量复核公开性、修订与硬条件，装配可信卡片和首次出现编号；测试首次发送前及最终提交前下架、修订变化、事实源故障、推荐回退标记与模型伪造链接。
- [ ] 3.5 实现 answer/no_results/clarification 判定及服务端模板；测试真实空结果、必要工具失败不能伪装无结果、缺少条件和未支持能力不声称已执行。
- [ ] 3.6 为助手历史、回合详情、上下文与事件提供同一可见性投影器；测试任一来源失效隐藏整块及失效元数据、旧消息兼容、事实源故障关闭读取和数据库原文/分页边界不变。
- [ ] 3.7 文档化回答及证据协议、partial/redacted 区别和语义校验局限；提供可由契约测试解析的成功、澄清和引用失效示例。

- [ ] 4.2 定义三个只读工具 manifest 与可信 ToolInvoker，逐调用检查身份、活动状态、严格参数、权限和预算；测试未知/写入工具、Prompt Injection、批量超额及原工具契约全部保留。
- [ ] 4.3 实现固定结构化约束、自然语言候选条件的受控锁定和当前结果精确条件复核；测试显式条件优先、模型覆盖/遗漏、无约束推荐绕过和未支持时间条件必须澄清。
- [ ] 4.4 实现有限上下文及空偏好来源：最近最多六个成功回合、完整回合裁剪、结构化指代和当前文章读取；测试旧引用重取、失败半成品/他人数据隔离、指代歧义及当前问题超限不截断。
- [ ] 4.5 在 Infrastructure 接入锁定版本 Eino ADK ChatModelAgent/Runner，以 ReAct 取证后独立流式成文；本地模型协议测试证明搜索→读取→回答、根据观察继续决策、成文预留和中间文本不输出。
- [ ] 4.6 实现每调用/累计输出及输入字节/审计预算，统一 deadline 并关闭隐式重试；确定性桩覆盖默认 4 次模型/6 次工具、缺 usage、Provider 忽略限制、超时、取消和能力不兼容，断言不会超预算再次调用。
- [ ] 4.7 更新示例 YAML、`.env.example`、Compose API 变量透传及配置参考；用配置解析测试核对设计表，运行时与文档均不包含真实密钥，不新增模型为 readiness 依赖。

## 5. 独立执行生命周期与终态提交

- [ ] 5.2 将执行上下文独立于 HTTP/SSE，所有业务动作及片段写入前检查授权/执行权/预算；测试订阅断开仍完成原回合、登录撤销/账户禁用停止、访问令牌自然到期仅影响订阅。
- [ ] 5.3 实现显式取消、最多一秒共享状态检测及下游 context 取消；跨执行器竞争测试覆盖 accepted/running/终态取消、幂等 200 和取消/成功先提交者唯一生效。
- [ ] 5.4 实现片段、来源及事件短事务提交，以及完整回答/唯一助手/预留消费/终态事件的原子提交；故障注入测试覆盖每个写入阶段回滚、迟到 owner 拒绝和最终提交不确定时查询而不重新生成。
- [ ] 5.5 实现 deadline、租约失效及保留期维护，固定有界批次且不自动重跑 running；真实数据库和可控时钟测试覆盖 accepted 排队超时、崩溃后五秒收敛、清理幂等和原 deadline 不延长。
- [ ] 5.6 接入 bootstrap 开关、关闭及重启顺序；测试生成关闭仍可查询/维护、优雅停止释放预留、数据库先停故障的租约兜底和重新启用先收敛过期回合。

- [ ] 6.2 实现五类持久事件及无位置的瞬态 stream.error，事务内序号和事件额度预留；测试先提交后投递、来源先于片段、并发有序、128/512 KiB 上限及终态预留。
